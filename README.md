# UMA CAREER

우마무스메 한 명을 초등부 1학년부터 고등부 3학년까지 24턴 동안 성장시키는 커리어 시뮬레이터 프로토타입입니다.

## Prototype

- 8개 출신 지역 및 지역별 초등학교 랜덤 배정
- 5개 초기 능력치와 숨겨진 포텐셜·안정성 생성
- 스프린터, 마일러, 라우터, 스테이어 성장 타입
- 초등부 6턴, 중등부 6턴, 고등부 12턴 진행
- 포텐셜 기반 성장과 안정성 기반 컨디션 변화
- 최근 5개 성장 로그 및 최종 커리어 리포트
- 데스크톱·모바일 반응형 UI
